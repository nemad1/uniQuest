Edit and improve the Vanguard student interface for the “Downtown” university platform.

Goal:
Make the Vanguard interface visually consistent with the existing Login Page and Guild Master/Admin Page. Use the same premium university style: deep navy background, gold highlights, glassmorphism cards, soft glowing accents, rounded corners, modern SaaS layout, and subtle gamified RPG energy.

Main Focus:
Strengthen the Points, Ranking, Leadership, and Certificate system. The Vanguard student should feel that helping others, completing missions, and mentoring juniors will help them build a visible campus reputation.

User Context:
The Vanguard is a student user. They can accept missions, mentor junior students, submit proof, earn points, climb ranks, appear on the leaderboard, and unlock digital certificates.

Visual Style:
- Use Deep Navy as the main background.
- Use Gold as the main reward/accent color.
- Use Cyan or Emerald only as secondary glow accents.
- Use glassmorphism cards with blur and transparent borders.
- Keep the design modern, clean, and similar to the login/admin pages.
- Add a subtle university map or “Downtown district” background pattern.
- Make the interface feel active, premium, and student-friendly.

Add or Improve These Sections:

1. Vanguard Status Header
Create a top profile/status section that shows:
- Student name
- Current rank badge
- Total points
- University verified badge
- Current major/year
- Small profile avatar
Example:
“Haitham — Gold Vanguard”
“2,450 Campus Points”
“Verified University Student”

2. Points System Card
Add a main reward card focused on points.
It should show:
- Current points balance
- Points earned this week
- Points needed for next rank
- Progress bar to next rank
Example:
“2,450 Points”
“+320 this week”
“550 points left to reach Diamond”
Use a gold progress bar with a soft glow.

- Bronze Vanguard
- Silver Vanguard

- Campus Legend

Important UX Rules:
- The student should instantly understand that points are valuable.
- Points should lead to rank progression, leaderboard position, and certificates.
- Mentorship should feel like a leadership activity, not just a chat.
- Keep the interface clean and not too crowded.
- Use clear visual hierarchy: Points first, missions second, certificates and leaderboard third.
- Maintain consistency with the Login and Admin page styles.

Microinteractions:
- Add hover glow on rank badges.
- Add progress bar animation for rank progress.
- Add small celebration animation when points are earned.
- Add locked/unlocked animation for certificates.
- Add smooth card hover effect for mentorship missions.

Main Dashboard Layout:
Top: Vanguard profile/status header.
Middle left: Points progress and rank ladder.
Middle right: Leaderboard preview.
Lower section: Mentorship rewards, active missions, certificate vault, and recent point activity.

Final Result:
The Vanguard dashboard should feel like a personal campus achievement center. It should motivate students to help juniors, complete missions, earn points, rise in ranks, appear on the leaderboard, and unlock official-looking certificates.
